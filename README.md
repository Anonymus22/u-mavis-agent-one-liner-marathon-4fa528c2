# One-Liner Marathon

A single-line joke about a smartwatch, a health check, and the moment the
listener realises the answer is too embarrassing to say out loud. The setup
leans on the familiar habit of asking a fitness gadget how you're doing,
then flips the punchline: the watch dodges the question in public. Short,
deadpan, and built to land on first read and hold up on the second.
